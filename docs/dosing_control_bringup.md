# BOOT 空管标定与串口滴定

固件统一使用人工标定和串口接单流程。在已激活 ESP-IDF 的工程目录执行
`idf.py build` 即可构建，无需选择台架模式。

| 功能 | ESP32-S3 接线 |
| --- | --- |
| BOOT 按键 | GPIO0，低电平有效 |
| 板载 WS2812 | GPIO48，由 RMT 发送 GRB |
| OGR350 模拟输出 | GPIO5 / ADC1_CH4，模拟地共地 |
| QLT1616 滴数输入 | GPIO4 / PCNT，已确认 3.3 V 空闲、过滴下降沿计数 |
| Kamoer 4460.5 | UART1，GPIO17 TX → 转换模块 RX，GPIO16 RX ← 转换模块 TX |
| 命令入口 | 原生 USB Serial/JTAG 或 UART0（115200、8N1） |

电机端使用 3.3 V 逻辑的自动收发 RS485 转换模块；RS485 A、B 接驱动板
P14 或 P15 中对应的 A(D+)、B(D−)，参考地按模块接法连接。驱动板
S1 第 1 位 OFF；S1 第 2 位 ON 时使用地址 1、9600、8N1。S1 第 5 位
按总线末端需求使用终端电阻。电机接 P1，驱动板电源接 P10。
电平确认后再接 GPIO4/5，传感器供电电压不可直接送入 ESP32-S3 GPIO。

| 灯色 | 阶段或结果 | 操作 |
| --- | --- | --- |
| 黄灯常亮 | 未标定 | 确认真正空管后，短按 BOOT |
| 绿灯 4 Hz | 正在标定 | 保持管路和光照稳定 |
| 红灯 1 Hz | 标定失败或无液超时 | 检查液源与传感器，确认空管，短按 BOOT 重试 |
| 绿灯常亮 | 已标定，等待滴定 | 在原生 USB 或 UART0（115200、8N1）发送 `10` 加回车 |
| 蓝灯 2 Hz | 正在执行滴定，包括尾滴观察和反向回收 | 等待结果；期间新命令不排队 |
| 红灯常亮 | 滴定中途失败 | 查看日志和停车应答，现场确认停车并排除故障后再重启 |

标定每 20 ms 采一次校准毫伏值；当前采 40 次，窗口最高值减最低值不超过
配置的 150 mV 时取同一窗口平均值。只在 RAM 保存本轮基准，上电不加载旧值。
实时电压须比基准**严格高出** 800 mV 才判有液。稳定液体也可能通过极差
判断，所以按 BOOT 前必须由操作者确认空管。没有芯片 ADC 毫伏校准时不接受标定。

启动日志应出现 `mode: dosing_control`。如果仍在连续打印旧的 ADC 日志，
请烧录新构建的固件。

串口命令支持原生 USB Serial/JTAG（Linux 通常为 /dev/ttyACM*）及 UART0 转串口。
两个入口独立解析，不可在一个口写数字、另一个口发回车。支持 CR、LF 或 CRLF
结束一行，只接受十进制 1–10000。绿灯常亮后发送完整一行，出现
`dosing: accepted target=10 source=USB`（或 `source=UART0`）表示已接单，
随即从泵预停和设置开始，无需再按键。调试器断点或 RS485 应答可能影响灯色
实际刷新和设备停机延迟。

到量以 GPIO4 的实际滴数为准。正向滴定从调用 START 前开始计时，默认最长
30 s。到量后先停泵，再观察尾滴，再运行原有的 500 ms 反向回收；反向
回收期间不按空管判断故障。蓝灯在最后一次 STOP 应答后才恢复绿灯。
30 s 未到量会尝试发 STOP；若确认计数有效且为零、ADC 判空管、STOP 已应答，
当前基准作废，回到可重标定状态。其它超时、计数错误、设备故障等为红灯常亮；
STOP 应答仍不等于物理停机，若没有应答应现场确认。

可在 `AF_config/dosing_control_config.h` 调整标定样本数、允许窗口极差、
有液增量、正向运行时限、泵速、方向和尾滴参数。默认泵速仍为 30 rpm，
固件上电不会自动启泵。

清水联调建议依次验证：上电黄灯且发送数字不启动；空管 BOOT 标定；
发送小滴数目标，验证正向到量、回收、绿灯；最后验证无液且零滴超时红灯闪烁。
