# 接口中文Doxygen与源码规则

## .h必须表达的契约

公共头文件用UTF-8无BOM、LF换行。文件开头使用`/** @file ... @brief 中文职责 */`。声明的公共函数、类型、枚举项、字段、函数指针和常量有中文Doxygen注释；行尾字段可使用`/**< 中文说明。 */`。

函数文档紧邻声明，包含：

- `@brief`：中文功能，说明动作是否已执行或只提交请求。
- `@param[in/out/in,out]`：每个参数的含义、单位、范围、NULL约束与缓冲区长度。
- `@return/@retval`：具体返回语义；错误函数列出本层会返回的符号码，可用`@return`补充“其他错误由端口原样传播”。不能只写0成功/其他失败。
- `@note`或`@details`：调用前提、任务/ISR上下文、阻塞上界、线程安全、指针寿命、失败后输出是否变化，以及必要的取消/完成规则。
- 有效的`@pre/@post`可补充前后条件；无参数/void返回不添加虚构标签。

```c
/**
 * @brief 读取温度快照，不主动触发新的采样。
 * @param[in] self 已完成初始化的设备实例，不得为NULL。
 * @param[out] temperature_mc 接收毫摄氏度温度，不得为NULL；失败时保持原值。
 * @retval FW_OK 已复制当前有效样本。
 * @retval FW_ERR_SENSOR_INVALID_ARG 参数无效。
 * @retval FW_ERR_SENSOR_NOT_READY 尚无有效样本。
 * @note 仅任务上下文调用；不等待硬件；同实例调用由调用者串行化。
 */
fw_error_t bsp_sensor_get_temperature(const bsp_sensor_t *self,
                                      int32_t *temperature_mc);
```

返回bool的纯谓词注明true/false；纯计算返回数值时注明单位与非法输入行为。返回指针的接口说明所有权和释放方式。非阻塞发送说明复制/借用、DMA/TC后何时可复用缓冲区。

ops声明的每个函数指针也按函数契约说明输入/输出、错误传播、是否接受BUSY及最大阻塞。示例中如使用统一接口注释约束多个同类回调，字段仍要有独立中文说明。

私有函数至少说明非直观行为与必要约束。不能以.c中的注释代替.h的公共契约，也不能粘贴旧芯片/旧文件名的模板注释。

## C编码细节

- C11为新建可移植模块的默认语言基线；目标编译器只支持其他版本时记录并使用其支持的子集，不为统一风格升级厂商编译环境。
- 使用4空格缩进、Allman大括号，if/for/while分支均带大括号；一个语句一行，switch各case清晰缩进。目标100列，长宏/链接等按需要例外。新模块可附clang-format配置，已有明确项目风格按用户约定映射。
- .c先包含自身头，后模块依赖、平台依赖、标准库；.h能独立编译，不能依赖调用方先include某个头。
- 指针用`const uint8_t *data`；输入只读数据加const，区分“指针本身const”和“指向数据const”。函数指针不做不兼容强转。
- 不使用无前缀的`OK/ERROR/READ/BUSY`宏；运行逻辑优先static函数或inline函数。带参数宏保证单次求值或明确约束，不能隐藏return/goto造成清理遗漏。
- 边界/协议字段用明确位宽；内部索引size_t；检查长度、整数溢出、符号/窄化转换、移位位宽和对齐。除法/平方根等计算说明有效范围。
- 输出先写局部临时值，成功后再提交；有意提供部分结果时另附有效长度/位图。禁止失败却留下看似有效的半份结果。
- 私有状态使用static或实例context，不让应用直接改内部状态。公共值类型context允许静态分配，但注明字段仅由模块API维护。
- 所有资源获取有对应释放；错误清理可用`goto cleanup`，不为单出口制造嵌套。检查cleanup结果，并与原始失败分别保存。
- 协议显式编码字节序和字段，不直接发送结构体内存；packed不解决字节序和对齐问题。
- 删除无效空操作和重复装饰注释，不制造空回调“假成功”；新增实现禁止无界等待、空死循环或未处理的TODO占位。

## 配置与改动约束

板级映射、器件规格、标定、控制参数和任务动作表分别归属，参数带单位、范围和默认来源。每个值只有一个权威输入，生成文件注明来源。业务代码不能重复硬编码另一套默认值。

保留原算法与行为的迁移，不顺带调PID、方向、容差或超时。普通后续修改仍按本规范补齐涉及接口的文档和错误语义，不要求每次重排未涉及的全部旧代码。
