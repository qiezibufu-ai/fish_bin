# QLT1616 液滴计数台架

接线实测已确认：QLT1616 与 ESP32-S3 共地，GPIO4 空闲约 3.3 V，液滴经过时约 0 V。
GPIO4 沿用板级输入配置，由 ESP32-S3 的 PCNT 采集下降沿。上升沿不计数。
短毛刺滤波初值为 1000 ns；传感器实际脉宽、拉丝引起的双脉冲和现场电机干扰仍需实测。

`AF_config/drop_count_test_config.h` 中 `APP_DROP_COUNT_TEST_ENABLE` 默认是 1。
此模式只启动 GPIO 和计数端口，电机 UART 不初始化，也不发送 START 或 STOP。
原有电机测试速度和开关不改；将计数模式设为 0 后恢复原电机测试入口。
两种模式当前不同时运行。

## 烧录后如何验证

1. 先确认泵已停止，传感器已供电且检测窗为空。打开 115200 串口监视器，
   重新启动已烧录的计数固件。应看到 `drop_count: GPIO4 falling edge; motor commands off`，
   随后一条 `total=0 delta=0`。如果上电时检测窗已有信号变化，等空窗稳定后记录初始值。
2. 空窗观察约 30 秒，`total` 应不变。用清水手动慢滴 10 滴，累计值应增加 10。
   再用人工或视频核对一组 100 滴，记录两组的起止值和实际滴数。
3. `total` 是本次上电的累计脉冲数；`delta` 是自上次输出增加的数量。
   每 200 ms 读一次，变化时才打印。短时间内两滴可能合并为一条 `delta=2`，
   因为 PCNT 在两次读取之间持续计数。重新开一组时用结束值减开始值，无需清零硬件。
4. 若单滴增加 2，先在 GPIO4 观察是否有两个下降沿；如果确实有，调整滴嘴与检测窗位置，
   排除拖尾和飞溅。若计数偏少，核对相邻两滴之间信号是否回到高电平，以及脉宽是否足够。
   若空窗仍增加，先检查 GPIO4 波形和传感器供电/共地。

## 软件边界

- PCNT 使用 SDK 的限位累加，后台只有一个应用任务读取；不挂 GPIO ISR，也不轮询电平数边沿。
- 滴定输入适配器提供累计值、有效标志和采样时间。有效标志表示 PCNT 读数有效，
  不代表传感器在线；气泡状态仍为未知。
- 当前仅观察滴数。目标滴数停泵、无滴超时、停车尾滴和毫升标定待单测通过后再集成。
- 构建验证使用 ESP-IDF v6.1。主机回归运行 `./tools/run_host_tests.sh`，
  SDK 替身覆盖单边沿计数、只读快照、故障记录和释放，以及两种台架模式。
  主机测试不验证真实波形或电机干扰。
